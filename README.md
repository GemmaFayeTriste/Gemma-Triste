# Gemma-Triste
Hi Good day this is Gemma Faye Triste from BSINTE 2A and this is my Mobile Application Called Daily Mood Journal
Daily Mood Journal is a simple mobile application that helps users track their daily emotions. Users can select a mood emoji, write a short note about their day, and view their mood history anytime.
Everyday, users can choose how they feel: Happy, Angry, Sad, Tired, or Excited.
How to install it? Open the link and after that the install area pop up when you open the link and wait for a seconds to download it.
